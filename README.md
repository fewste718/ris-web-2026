## Запуск клиента

Требуется Node.js 24 LTS версии 24.12 или новее.

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес из терминала, обычно http://localhost:5173.

В приложении три экрана: список заявок, создание заявки и вход. Используются тестовые записи; формы не отправляют данные и не выполняют авторизацию.

Проверка сборки из папки `frontend`:

```bash
npm run build
```
